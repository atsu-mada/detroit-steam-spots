# Detroit steam spots

Street-level views of places in downtown and midtown Detroit where steam rises from the street.

- Page: https://atsu-mada.github.io/detroit-steam-spots/
- 43 spots grouped into 20 representative points, one Mapillary photo per point
- Approach clips to two spots, built from one continuous Mapillary sequence each
- Driving route between the two spots (Google Maps)
